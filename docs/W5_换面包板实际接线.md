# W5：换面包板接线（以实际运行固件为准）

先拔 USB 并拍旧板正面照片。新板的孔位编号可以不同，按下列电气节点转移；不要照计划 PDF 的 GPIO1/2/4 或 GPIO5 灯环方案重接。

## 供电节点

- ESP32-S3 `3V3` → 新板 3V3 正电轨。DRV2605L `VIN`、LIS3DH `VCC`、FSR 一端、灯环红线都接这条 3V3 节点。
- ESP32-S3 `GND` → 新板 GND 负电轨。DRV `GND`、LIS `GND`、按钮一端、FSR 下拉电阻一端、灯环黑线都接这条 GND 节点。
- USB-C 给 ESP32 供电；`5V/VIN` 脚、电池、升压模块本轮不用。若新面包板电源轨在中间断开，要用跳线桥接同名的 3V3 或 GND 轨，绝不能把两种电轨互连。

## 信号节点

- `GPIO8` → DRV `SDA` 和 LIS `SDA`。
- `GPIO9` → DRV `SCL` 和 LIS `SCL`。
- `GPIO4` → FSR 另一端和 `10kΩ` 电阻一端；电阻另一端 → GND。这是一个三线相接的采样节点。
- `GPIO5` → 常开按钮另一端；按钮第一端 → GND。固件使用内部上拉，不另接电阻。
- `GPIO6` → `330Ω` 串联电阻 → 灯环黄线 `DIN`（不是 `DOUT`）。
- DRV `OUT+`、`OUT−` → 1027 ERM 的两根线；两个输出都不要接地或 3V3。
- LIS3DH 如果旧板上另有 `CS`、`SDO/SA0` 接线，原样转移；当前实际 I2C 地址是 `0x19`，不要随意改地址选择。

转移顺序：电源轨 → ESP32 → DRV/LIS I2C → FSR 与 10kΩ → 按钮 → 灯环 → 马达。所有转移和检查完成后才插 USB。按 115200 查看 `DRV: OK`、`LIS3DH: OK`；再测按压、灯、马达、按钮。旧面包板暂时保留到新板全部通过。
