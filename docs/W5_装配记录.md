# W5：无焊接台架装入玩偶

状态：已收到玩偶正面与面包板尺寸对比照片 `photos/1117_W5_玩偶与面包板尺寸对比.jpg`，背部可打开；用户已实测带线面包板能放入。已重新上传 `firmware/companion_v1_breath/companion_v1_breath.ino`；装好后复测按压、灯环、按钮与马达。

## 这只黄色玩偶的具体位置

- FSR406：正面下半部中央，笑脸下方的“肚子”位置，让拥抱或手掌能压到；感应方片平铺，尾巴向下沿内部走线，不折直角。
- 毛毡：FSR 与外层绒布之间，盖住感应方片；约 5–6 cm 圆角薄硬卡片在 FSR 的内侧做背衬。
- 1027 ERM：贴紧背衬硬卡片的内侧边缘，避开 FSR 方形感应区的正后方；延长线沿玩偶内壁向背部走，两个鳄鱼夹金属部分分别绝缘。
- 16 灯灯环：正面偏右侧、略高于 FSR 的位置，朝向绒布外侧，与 FSR 错开；先透光测试，不先剪绒布。
- ESP32-S3、DRV2605L、LIS3DH-A 与整块面包板：作为一个单元放在玩偶背部下半部偏后，置于绝缘盒或包覆绝缘的硬托板内，四周用填充棉缓冲；ESP32 USB 口朝背部开口。
- 按钮：背部开口旁、靠下的位置，使用者伸手能摸到；不要埋入棉花。
- USB：从背部开口下缘引出，在盒或托板处固定线缆，避免拉力传到 ESP32 插座。

## 本轮装配范围

- USB 供电；不接锂电池与升压模块。
- 只装一片已验证的 FSR406、一颗 1027 ERM、一个 16 灯灯环、一个按钮，以及 ESP32-S3、DRV2605L、LIS3DH-A。
- ESP32 和模块仍插在面包板上，必须整体放入绝缘盒并固定；不可让松散的杜邦线承担拉力。
- 传感器、马达、灯环和按钮的接头分别绝缘并留少量线长。

## 计划顺序

1. 断开 USB，拍当前接线全景，给各线贴标签；打开玩偶拉链并只取出够放盒子的填充棉。
2. 找到合适的绝缘盒或卡纸盒，装入面包板，确保盒盖不压排针和杜邦线。USB 线从侧边穿出并固定在盒上。
3. 控制盒放在底部偏后，四周加填充棉，暂不封口。
4. 胸前从外到内：绒布 → 毛毡 → FSR 感应区（尾巴向下走线）→ 圆角硬卡片。马达固定在卡片背面，避开 FSR 正中。
5. 灯环贴胸口偏上或偏侧、朝外；先通电透光测试，再决定是否需要开窗。灯环仍只接原来的 3V3、GND、GPIO6。
6. 按钮固定在能从外部摸到的位置；所有线沿背面到控制盒，接点逐个绝缘，留出松弛量。
7. 合上拉链前短时通电，复测呼吸灯、按压灯光/震动、按钮暂停恢复；再抱着轻轻晃动检查松线。

## 证据

玩偶外观和拉链、空腔、胸前层叠、控制盒、走线、合口后的成品照；装好后的功能复测结果。

注意：W4 的强度 `40–55` 是台架数值，隔着毛毡和绒布后要重新评价触感。
