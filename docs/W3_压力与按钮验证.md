# W3：压力与按钮验证

实际接线以当前可运行的原型为准：FSR1 经 10kΩ 下拉接 GPIO4，按钮接 GPIO5 与 GND。原计划中的 GPIO1、GPIO2、GPIO4 不适用于这套已接好的台架，不能直接照抄。

已通过：FSR 数值随按压变化；按钮能暂停与恢复；整合后再次复测正常。

按钮证据：串口依次出现 `PAUSED`、`ENABLED`，截图为 `photos/1116_W3_按钮暂停.png` 和 `photos/1116_W3_按钮恢复.png`。

2026-11-16 串口读数（12 位 ADC 原始值）：空载持续 `0`；轻压约 `587–1071`；重压约 `2288–3321`。轻压灯级 `2–3`，重压灯级 `4`。三个状态的截图分别存于 `photos/1116_W3_FSR空载.png`、`photos/1116_W3_FSR轻压.png`、`photos/1116_W3_FSR重压.png`。这只是本次手指按压的范围，尚未换算成重量。

毛毡垫层初测：同一瓶水通过平整硬纸板施压，空载 `0`，负载 5 秒约 `2197–2231`，范围宽度 `34` ADC 计数。截图为 `photos/1116_W3_毛毡空载.png`、`photos/1116_W3_毛毡负载.png`。

移开水瓶后，下一条可见串口读数已为 `0`（串口每 500 ms 打印，不能据此确定更精确的回弹时间）。证据为 `photos/1116_W3_毛毡回弹.png`。现场没有泡棉，用户决定本轮只测试毛毡；因此不能得出“毛毡优于泡棉”的比较结论。
