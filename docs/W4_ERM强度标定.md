# W4：1027 ERM 强度标定

2026-11-17 使用 `firmware/w4_erm_calibration/w4_erm_calibration.ino`。实际接线保持 ESP32-S3 GPIO8/9 I2C、DRV2605L `0x5A`、1027 ERM 马达不变。

测试程序通过串口监视器输入整数 `0–127` 并回车；每次只驱动 1.5 秒，然后自动写入 `RTP=0` 停止。波特率 115200，行尾选择 `New Line`。上传成功，发送 `20` 后串口出现 `RTP=20` 和 `RTP OFF`，输入与自动停止机制通过。

待由手触摸确认：

- `RTP_MIN`：刚好能稳定感觉到、不会时有时无的最小值，略向上留余量。
- `RTP_MAX`：明显但不刺耳、不令人烦躁的最大值，不能只按数字猜。
- 最终 4 秒周期起伏与连续运行 5 分钟的触感和温升。
- 手触马达的视频与串口截图。

1027 是 ERM；其振幅与转速耦合，不能把它描述成 LRA 或真正的机械呼吸。标定期间按压、灯环与移动交互暂时停用，完成后再上传整合固件。
