# W2：呼吸灯验证与整合

- 日期：2026-11-16。
- 独立测试程序：`firmware/w2_breathing_ring/w2_breathing_ring.ino`。
- 实际接线：16 颗 WS2812B，3V3 供电，共地，GPIO6 经 330Ω 接 DIN。
- 灯效：暖橙色，约 4 秒一轮，低亮度。用户反馈“灯光正常”，5 秒以上视频存于 `photos/1116_W2_灯环呼吸测试.mp4`。
- 整合程序：`firmware/companion_v1_breath/companion_v1_breath.ino`。保留原有按压、按钮、移动和马达逻辑；启用时灯环低亮度呼吸，按压时前 1–4 颗增强，暂停时熄灭。
- 整合程序编译并上传成功。用户已复测确认：空闲呼吸、按压灯光与震动、移动震动、按钮暂停与恢复四项均正常。

3V3 给标称 5V 的灯环供电仅用于当前低亮度台架原型。正式版本应改为 5V 供电并增加合适的 3.3V→5V 数据电平转换与独立电流预算。
