## 当前硬件与接线（以实际台架为准）

| 器件 | 实际接法 |
| --- | --- |
| ESP32-S3 N16R8 | USB-C 供电与烧录 |
| FSR406 | 一端 3V3；另一端接 GPIO4，并经 10kΩ 电阻接 GND |
| 常开按钮 | GPIO5 与 GND，使用内部上拉 |
| DRV2605L + 1027 ERM | VIN 3V3，GND 共地，SDA GPIO8，SCL GPIO9；马达接驱动输出 |
| LIS3DH | VCC 3V3，GND 共地，SDA GPIO8，SCL GPIO9；实际 I2C 地址 `0x19` |
| 16 灯 WS2812B 灯环 | 红线暂接 3V3，黑线 GND，黄线 DIN 经 330Ω 接 GPIO6 |

灯环原标称 5V，目前接 3V3 属于临时台架方案。现有固件最多点亮 4 颗低亮度灯。5V 不亮的原因尚未测定。电池和升压模块尚未接入。

## 运行已验证 V0

1. 在 Arduino IDE 中打开 `firmware/companion_v1_light/companion_v1_light.ino`。
2. 选择 `ESP32S3 Dev Module` 和正确 USB 串口，确认已安装 ESP32 开发板包及 `Adafruit NeoPixel` 库。
3. 上传后打开串口监视器，波特率 `115200`。应看到 `DRV: OK`、`LIS3DH: OK`。
4. 压 FSR：亮 1–4 颗琥珀色灯，并震动一次。松开：灯灭。按按钮：启用／暂停。明显移动：触发两次震动；门槛约 8000，触发后至少 8 秒且安静 2 秒才重新待命。串口发送 `v` 可手动震动一次。

V0 串口输出是状态文本，**还不是 W6 所要求的 CSV 日志**。`a、d、s、h、f、q、x` 等第 1 档命令尚未实现。
